## What is Sentrix Labs?

**Sentrix Labs** is the protocol home of **[Sentrix Chain](https://sentrixchain.com)** — an open-source Layer 1 blockchain built in Rust with EVM compatibility.

We work on the core protocol, validator infrastructure, consensus, execution, RPC, contracts, developer tooling, and ecosystem standards around Sentrix Chain.

Sentrix is still early and actively being hardened.

> Building real blockchain infrastructure from Indonesia — protocol, validators, RPC, indexers, contracts, apps, and developer tools.

---

## What we are building

Sentrix Chain combines a Rust-native chain core with familiar EVM tooling.

Core areas include:

- Rust chain core
- DPoS + BFT consensus
- Native + EVM execution
- EVM runtime powered by `revm`
- libp2p networking
- MDBX-backed storage
- JSON-RPC, WebSocket, REST, gRPC, and gRPC-Web
- Validator and fullnode operations
- Canonical contracts and ecosystem standards
- Developer tooling, documentation, and examples

User-facing products such as the explorer, wallet, faucet, launchpad, SDKs, and apps live under **[SentrisCloud](https://github.com/sentriscloud)**.

## Contributor areas

We are opening more of the Sentrix ecosystem for contributors.

Good areas to help:

- Rust protocol engineering
- BFT consensus and validator liveness
